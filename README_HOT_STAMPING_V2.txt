Hot Stamping Calculator V2 Supabase

Fichiers pour GitHub/Vercel :
- index.html
- manifest.json
- logo-hot-stamping.png
- icon-192.png
- icon-512.png
- apple-touch-icon.png
- hot_stamping_v2_setup.sql

Ce pack garde les couleurs et le dessin du logo d'origine, mais remplace le texte "FPM Fine Packaging Manufacturers" par "Hot Stamping".

Installation :
1. Dans Supabase > SQL Editor, executer hot_stamping_v2_setup.sql.
2. Dans GitHub, remplacer/ajouter les fichiers ci-dessus.
3. Commit changes.
4. Vercel redeploie automatiquement.
5. Ouvrir l'application et tester + Machine, + Support, + Folio, puis Enregistrer calibration.
